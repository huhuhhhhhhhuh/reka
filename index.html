Подойдёт вертикальный портрет окраса — например, как раз ~100×150px, картинка впишется без обрезки в карточку прогресса. Файлы больше ~1 МБ лучше сначала сжать.

Другим станут видны только имя, роль, знак (или картинка), и число полученных наград, на вкладке «Соплеменники». Заметки и детальный прогресс по каждой медали остаются только у тебя.

Ссылка работает для тех, кто тоже открывает этот трекер здесь же, в Claude — при переходе по ней сразу откроется карточка твоего профиля. Если хочешь отправить прогресс куда угодно (в чат, на форум) — используй кнопку «Скачать карточку прогресса» на вкладке «Статистика», она работает как обычная картинка.
